# The generated study podcast

Living proof of what agent-readable resources buy you: this two-host audio briefing about Pimcore was generated by an AI agent from the public resources this guidepost maps (docs.pimcore.com/platform/llms.txt, the skills repos, the Agent Bundle docs), then synthesized locally on macOS. No cloud TTS, no data leaving the machine.

- `script.md`: the two-host script (S = Samantha, host; D = Daniel, expert)
- `generate.sh`: synthesizes `study-podcast.m4a` from the script using macOS `say` + ffmpeg

```bash
./podcast/generate.sh   # needs macOS and ffmpeg (brew install ffmpeg)
```

The point for your own product: when your docs serve markdown, your skills are installable, and your resources are discoverable, a machine can brief your next hire. If an agent cannot produce this for your product, you found your gaps.
